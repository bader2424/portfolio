# Bader Bahashwan Portfolio

Source code for my personal portfolio, built to present my work as a Full-Stack and DevOps Engineer.

Live portfolio: [Visit my portfolio](https://bader2424.github.io/portfolio/)

## Reuse

You may use this repository as a reference or starting point for your own portfolio. Please replace the personal information, project descriptions, contact links, resume, and certificates before publishing.

Do not present this portfolio's personal content or project work as your own.

## Where to Edit

- Update page structure, contact links, and the resume link in `index.html`.
- Update English and Arabic content in `script.js`.
- Adjust visual styles in `refine.css`.

## Run locally

Clone the repository first:

```bash
git clone https://github.com/bader2424/portfolio.git
cd portfolio
```

Then open the site:

```powershell
# Windows PowerShell
Start-Process index.html
```

```bash
# macOS Bash
open index.html
```

On Linux, use `xdg-open index.html` instead.
