# Bader Bahashwan Portfolio

Personal one-page portfolio for a Full-Stack and DevOps engineer.

Live site: [bader2424.github.io/portfolio](https://bader2424.github.io/portfolio/)

## Run locally

No build step or dependencies are required.

```powershell
py -m http.server 8000
```

Then open `http://localhost:8000`.

## Customize

- Update page structure, contact links, and the resume link in `index.html`.
- Update English and Arabic content in `script.js`.
- Adjust visual styles in `refine.css`.

The site supports English and Arabic (RTL), responsive layouts, a downloadable CV, and GitHub project links.

## Reuse

Feel free to clone this repository and use it as a starting point for your own portfolio. Replace the personal information, project descriptions, contact links, resume, and certificates before publishing.

Do not present this portfolio's personal content or project work as your own.
